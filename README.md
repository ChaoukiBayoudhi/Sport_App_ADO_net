# Sport App ADO .NET

## Tech stack

- C# / .NET
- Windows Forms
- Target framework: v4.8
- ADO.NET (SqlClient)

## Contents

- Forms: AddPlayerForm, Form1, ShowPlayersForm
- Classes: DataBaseConnection, Player

## How to run

Open `Sport_App.sln` in Visual Studio (Windows) and press F5. The app connects to SQL Server: update the connection string to your own server first.
